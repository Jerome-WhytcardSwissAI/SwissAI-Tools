# SwissAI-Tools — catalogue public

**139 ressources documentées** au 16 novembre 2026, dont **44 serveurs MCP** et **42 API**.

Chaque ligne renvoie vers l'éditeur, la documentation ou le dépôt original. Les **sources secondaires, preuves et limites** figurent dans le [JSON complet](catalogue/outils.json), qui constitue la version structurée.

Les ressources ne sont pas classées par valeur commerciale. Elles sont groupées par mode d'accès, avec des thèmes de recherche. Une interface commune ne signifie pas que tous les services sont gratuits, publics ou opérés en Suisse.

## Précautions de lecture

- **Source présente ne signifie pas accès testé.** Le catalogue atteste une documentation trouvée, pas l'exécution d'une API ou d'un MCP.
- **Un MCP communautaire n'est pas une API officielle.** La fiche renvoie distinctement au dépôt du connecteur et aux sources publiques consommées.
- **Les restrictions ne sont pas uniformes.** Certains outils exigent un compte, un accord commercial, des clés ou une licence spécifique.
- **Portefeuille MCP :** certaines fiches proviennent du [registre public de Swiss Public Data MCP](https://github.com/malkreide/swiss-public-data-mcp/blob/main/portfolio.json), dont l'inventaire indique une dernière vérification interne au 18 août 2026. Elles ne sont pas attestées comme installées et fonctionnelles dans le présent environnement.
